# בקטנה — פשוט לקנות

השוואת מחירי מזון ופארם בין רשתות ישראליות, על נתוני חוק שקיפות המחירים. הכל חינם.

- `ingest/` — פייתון שמושך כל יום את **הקטלוג המלא** מכל רשת, ומעדכן את ה-DB.
- `supabase/schema.sql` — הטבלאות. `migration_v3_cleanup.sql` — ניקוי חד-פעמי (ראה למטה).
- `web/` — האתר (קובץ HTML אחד, בלי build).
- `.github/workflows/` — `ingest.yml` (משיכה פעמיים ביום), `images.yml` (תמונות).

## איך הנתונים נשמרים (ולמה)

- **רק קובצי PriceFull/PromoFull.** קובצי `Price`/`Promo` הם עדכוני שינויים בלבד (לפעמים 2-5 פריטים) ולכן לא מייצגים מה יש בסניף.
- **ברמת רשת, לא סניף.** לכל (מוצר, רשת) שורה אחת ב-`prices`: `price` = הזול בין הסניפים, `price_max` = היקר, `stores_carrying` = בכמה סניפים המוצר נמצא. קטלוג מלא ברמת סניף הוא עשרות מיליוני שורות ולא נכנס ב-500MB החינמיים; ברמת רשת זה מאות אלפי שורות. ההשוואה ממילא פועלת ברמת רשת.
- **"אין במלאי" = המוצר לא הופיע באף קובץ PriceFull של הרשת בעדכון האחרון.** מסמנים את זה רק אם *כל* הקבצים של הרשת נמשכו בהצלחה ורשימת הקבצים שלמה, ורק אם לא נעלמו יותר מ-50% מהמוצרים בבת אחת (סימן לתקלה, לא למלאי). אחרת לא נוגעים.
- **כתיבה רק של מה ששונה** מאז הריצה הקודמת; מוצר שלא נראה 30 יום נמחק.
- `ingest_status` — לכל רשת: מתי הסתיימה משיכה מלאה ובכמה סניפים. מזה האתר מציג "עודכן לפני...".

## התקנה (פעם אחת)

1. **Supabase** (חינם, בלי כרטיס): להריץ את `supabase/schema.sql` ב-SQL Editor. מפתחות מ-Project Settings → API Keys.
2. **GitHub**: secrets בשם `SUPABASE_URL` ו-`SUPABASE_SERVICE_KEY` (מפתח ה-secret/service_role, לעולם לא בקוד). הריפו ציבורי = דקות הרצה בלתי מוגבלות.
3. **Storage** לתמונות: bucket ציבורי בשם `product-images`.
4. האתר: לעדכן `SUPABASE_URL`/`SUPABASE_ANON_KEY` בראש `web/index.html` ולפרסם (Netlify/GitHub Pages).

## הוספת רשת

שורה אחת ב-`ingest/config.py`. רשתות בפורטל המשותף (Cerberus) צריכות רק שם משתמש. רשת שלא אומתה (`verified=False`) שנכשלת — מדולגת עם אזהרה בלוג בלי להפיל את הריצה. בסוף כל ריצה יש בלוג `SUMMARY` עם סטטוס כל רשת.

## בדיקות

```bash
SUPABASE_URL=https://x.supabase.co SUPABASE_SERVICE_KEY=x python -m unittest ingest.tests.test_pipeline -v
```
רצות אוטומטית לפני כל משיכה ב-GitHub Actions; אם נכשלות - המשיכה לא מתחילה.
